# Cadastro de Produtos — Avaliação Continuada de Python

Projeto desenvolvido para a avaliação continuada da disciplina de programação em Python.

## Objetivo

Criar um sistema simples de gerenciamento de produtos no terminal, utilizando as quatro operações do CRUD: **Create, Read, Update e Delete**.

## Banco.py

Apenas um registro dos meus estudos tentando utilizar sqlite
## Funcionalidades

- [ ] Adicionar produtos com descrição e preço.
- [ ] Listar os produtos cadastrados.
- [ ] Editar um produto (a implementar).
- [ ] Excluir um produto (a implementar).
- [ ] Sair do programa.

## Como executar

É necessário ter o **Python 3** instalado. No terminal, execute:

```bash
python3 cadastro-produtos.py
```

## Como funciona

O programa apresenta um menu de opções. Os produtos são armazenados em uma lista de dicionários, com os campos `descricao` e `preco`.

**Observação:** os dados ficam apenas na memória e são perdidos quando o programa é encerrado.
